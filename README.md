# Monster Puzzle Fight

Real-time multiplayer monster puzzle fight game with WebSocket-based matchmaking and combat system.

## Features

- Auto-matchmaking system
- Real-time puzzle-based combat
- Element affinity system
- Skill system
- Server-authoritative gameplay

## Tech Stack

- Node.js + TypeScript
- WebSocket (ws)
- Express
- Railway (deployment)

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Project Structure

See `docs/` folder for detailed documentation on each system.

## Deployment

Configured for Railway with `railway.toml`. Push to deploy.
